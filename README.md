# E-Commerce Sales & Customer Analytics Dashboard

## Project Overview

An interactive Power BI dashboard built to analyze e-commerce sales, products, customers, and regional performance.

The project uses the UCI Online Retail dataset and transforms raw transaction data into an interactive three-page business dashboard.

## Dashboard Pages

### 1. Executive Overview
- Total Sales
- Total Orders
- Total Customers
- Total Quantity
- Average Order Value
- Monthly Sales Trend
- Top 10 Products by Sales
- Top 10 Countries by Sales
- Sales by Country

### 2. Product Performance
- Top 10 Products by Sales
- Monthly Sales Trend
- Top 10 Products by Quantity
- Sales vs Quantity by Product

### 3. Customer & Regional Analysis
- Total Customers
- Total Orders
- Average Order Value
- Top 10 Customers by Sales
- Sales by Country
- Orders by Country
- Customer Orders vs Sales

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
- GitHub

## Data Preparation

The dataset was cleaned using Power Query by:
- Removing cancelled transactions
- Removing blank Customer IDs
- Removing invalid quantities
- Removing invalid unit prices
- Creating a Sales Amount column
- Creating a Date table for time-based analysis
